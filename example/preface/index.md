这本小书是 [pdf-book-exporter](https://github.com/rootsongjc/pdf-book-exporter) 的示例，同时也是它的回归测试。书的来源是一个普通的 Hugo 书籍目录：每一章是一个 page bundle，章节顺序由 `weight` 决定，分部（Part）在 `_index.md` 里声明。导出时无需任何改动。

## 这本书怎么组织

- **前言**不属于任何分部，直接排在正文最前面。
- **第一部分 · 基础排版**覆盖文本、列表、引用、脚注、代码块和表格。
- **第二部分 · Hugo 与进阶**演示 Hugo 短代码如何映射到印刷排版，以及数学公式、任务列表等进阶内容；其中一章带有嵌套的子章节。
- **附录**使用 A、A.1、图 A-1 的编号方式。
- 目录里有一章标记了 `draft: true`，默认不会出现在 PDF 里。

## 怎么导出

```bash
pdf-book-exporter example -o example.pdf
```

一本千页的书也只需几秒。导出完成后对照本书的每一章检查排版，就能知道模板的改动有没有破坏什么。

## 约定

正文中出现的 ✅ 表示该特性已经支持；带有 ⚠️ 的段落说明印刷版与网页版的差异。本书所有内容都可以在 Hugo 网站上正常渲染——这正是这个工具的目标：**一份 Markdown，两种产出**。
