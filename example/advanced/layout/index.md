## 多层嵌套列表

1. **前端技术栈**
   1. **框架选择**
      - React
        - 优点：
          - 组件化开发
          - 虚拟 DOM 性能优化
          - 丰富的生态系统
        - 缺点：
          - 学习曲线陡峭
          - 需要额外的状态管理库
   2. **构建工具**
      - Webpack
      - Vite
      - Parcel
2. **后端技术栈**
   1. **语言选择**
      - Node.js
        - 优点：JavaScript 全栈
        - 缺点：单线程限制
      - Python
        - 优点：简洁易读
        - 缺点：性能相对较低

## 引用块作为提示

没有使用短代码时，带 emoji 和粗体标题的引用块是网页上常见的提示写法，印刷版按普通引用处理：

> ⚠️ **警告**
>
> 这是一个警告信息，用于提醒用户注意重要事项。

> ℹ️ **信息**
>
> 这是一个信息提示，用于提供额外的说明。

> ✅ **成功**
>
> 操作已成功完成！

> ❌ **错误**
>
> 发生了错误，请检查输入并重试。
